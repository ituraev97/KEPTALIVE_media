# KEPT ALIVE — media pipeline

English documentary channel for the US: how medicine keeps people alive (military medicine, hospital ships, outbreaks, medical firsts, how procedures work). Real public-domain footage + own graphics. 1 long video + 6 Shorts per day via Metricool.

- `RUNBOOK.md` — daily production steps (the scheduled task follows it)
- `pipeline/` — fork of CHANNEL 16 (graphics, build, finish, shorts, thumbnails), voice `vfx.py` (Kokoro am_fenrir + processing)
- `topics.md` — season queue · `templates/` — description · `brand/` — logo, banner, avatar, watermark
- Video files live only on `drop-mon` … `drop-sun` branches (raw links for Metricool), never on `main`.
